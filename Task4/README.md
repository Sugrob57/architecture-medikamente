# Задание 4. Оценка узких мест при миграции

В компании планируется миграция устаревшей монолитной системы на современную архитектуру (например, на микросервисную). В процессе перехода необходимо выявить потенциально узкие места, которые могут негативно повлиять на работоспособность нового решения.

# Решение

### Текущее состояние системы

### Процессы и компоненты, затрагиваемые миграцией

| Процессы и компоненты              | Описание                                                     |
|------------------------------------|-----------------------------------------------------------------|
| **Данные клиентов в Excel**        | Миграция с Excel на СУБД                                                          |
| **Данные клиентов в сканах**       | Миграция в файловое хранилище + определение закономерностей именования файлов     |
| **Базы данных 1С**                 | Миграция из файловой БД в распределенную и масштабируюмую СУБД                    |
| **Аутентификация/Авторизация**     | Переход к централизованному IAM, разделение прав, интеграция с Active Directory   |
| **Бизнес-логика**                  | Выделение и разработка микросервисов, интеграция с IAM, сбор требований           |
| **Серверная инфраструктура**       | Переход с физического сервера на микросервисную архитектуру, поддержка систем и разработка CI/CD процессов |
| **Внешние интеграции**             | Организация каналов внешней интеграции - авторизация, API-контрактыб тех.документация                      |
| **Доступность и масштабируемость** | Важно учесть на старте векторы архитектурного развития, с учетом PrivacyByDesign, отказоустойчивости и масштабируемости  |
| **Команда и навыки**               | Недостаток ИТ-специалистов. Понадобятся DevOps, ИБ-специалисты, команда разработки и поддержки                           |
