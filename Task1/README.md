# Задание 1. Анализ безопасности системы

Чтобы заниматься реализацией новых продуктов, которые основаны на данных, необходимо системно решить проблему хранения конфиденциальных данных и управления ими. Сейчас данные лежат в непосредственной близости к пользователям, поэтому существует риск утечки данных и неправомерного использования информации.

Чтобы защитить данные, используйте механизмы, инструменты и принципы работы с конфиденциальными данными, например, подходы Privacy By Design, Data Minimization и Data Lineage.

В рамках этого задания вам нужно проанализировать состояние As-Is, чтобы впоследствии приступить к его доработке.

# Решение

## Конфиденциальные данные 
В настоящий момент компания оперирует следующими конфиденциальными данными:
| Данные | Описание |
|--------|----------------|
| Персональные данные | ФИО, дата рождения, телефон, email, адрес прописки, место работы/учебы  |
| Медицинские данные | Диагнозы, жалобы, результаты анализов, назначения  |
| Финансовые данные | Сумма платежей, номера договоров, банковские реквизиты  |
| Операционные данные | Даты приемов, номера кабинетов, время записи  |

## Аудит мер по обеспечению безопасности данных

В компании есть следующие проблемы с данными:

| Проблема | Описание |
|--------|----------------|
| Отсутствуют ограничения доступа | Excel-файлы и сканы хранятся на общем диске. Доступ есть у всех сотрудников | 
| Отсутствует аудит доступа | Excel-файлы и сканы хранятся на общем диске. Доступ есть у всех сотрудников | 
| Не фиксируется история изменений |Excel-файлы меняются бесконтрольно, история изменений не ведется | 
| Срок хранения не установлен | Нет никаких упоминаний удаления данных по времени или по запросу клиента | 
| Данные собираются и хранятся избыточно | Клиент может заполнить расширенную форму, данные которой не требуются в компании  | 
| Данные собираются и обрабатываются вручную | Сотрудники заполняют данные вручную, возможно искажение данных  | 


## Рекомендации по улучшению

| Рекомендация | Описание |
|--------|----------------|
| Ролевая модель | Организовать ролевую модель внутри организации и разграничить доступ к ресурам на основе ролей |
| Удаление и архивация | Обеспечить удаление устаревших данных и/или их архивацию | 
| Интерфейс для работы с данными | Данные не должны напрямую добавляться и редактироваться в системе хранения. Нужно добавить интерфейс для ввода и редактирования. Это позволит орагизовать аудит изменений и управлять доступом |
| Data Minimization | Прекратить сбор излишних данных |
| Классификация и тегирование | Определить каким сотрудникам и какие данные нужны, раграничить формы просмотра (например мед.лаборатории вообще не нужна информация о ФИО клиента) |
| Шифрование | Обеспечить механизмы шифрования данных на всех этапах | 
| Система хранения | Внедрить систему централизованного хранения данных, соответсвующую всем указанным пунктам |
